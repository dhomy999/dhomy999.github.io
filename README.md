# الموقع الشخصي

هذه نسخة مستقلة وجاهزة للنشر من موقع عبد الرحمن الجهني. لا تحتاج إلى بناء أو تثبيت أي حزم.

## النشر

1. أنشئ مستودعًا عامًا باسم `USERNAME.github.io`.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع.
3. من إعدادات المستودع افتح **Pages** واختر النشر من فرع `main` والمجلد `/ (root)`.

سيكون الرابط: `https://USERNAME.github.io/`.
